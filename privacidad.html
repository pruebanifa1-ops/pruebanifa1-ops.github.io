Última actualización: 7 de octubre de 2026

1. Alcance

Esta política se aplica a este sitio web y a la aplicación interna "Archivo Oculto Uploader", que el canal de YouTube El Archivo Oculto utiliza para publicar y gestionar sus propios vídeos.

2. Uso de los Servicios de API de YouTube

"Archivo Oculto Uploader" utiliza los Servicios de API de YouTube. Al interactuar con ella aceptas las Condiciones de Servicio de YouTube, y los datos se tratan también conforme a la Política de Privacidad de Google.

La aplicación solo la usa el propietario del canal y solo accede a la cuenta de ese canal para:

  • subir vídeos y editar sus títulos, descripciones y etiquetas;
  • gestionar listas de reproducción del propio canal;
  • consultar las estadísticas del propio canal para mejorar los contenidos.

No accede a datos de otros usuarios de YouTube, no los recopila, no los almacena y no los comparte con terceros.

3. Datos que se guardan

Los únicos datos que se conservan son las credenciales de autorización de la cuenta del propio canal, almacenadas de forma privada y nunca publicadas, y las estadísticas agregadas de sus vídeos. Se eliminan si se revoca el acceso.

4. Este sitio web

Este sitio es estático: no usa cookies, formularios, analítica ni publicidad, y no recoge datos personales de quienes lo visitan.

5. Cómo revocar el acceso

El acceso de la aplicación a una cuenta de Google puede revocarse en cualquier momento desde la página de permisos de seguridad de Google.
